# Survey layout references

This directory contains layout references used to revise the presentation of the manuscript. They are not part of the 211-record evidence map and do not support technical claims in the survey.

The comparison focused on five recurring choices: the role of the opening overview figure, the mapping between taxonomy and section order, the density of full-width tables, the length of table cells and captions, and the use of a restrained visual palette. The revised manuscript follows the shared conventions rather than copying the graphics of any one paper.

The folder includes surveys on robotics foundation models, vision-language-action models, real-world VLA deployment, self-evolving language models, and agent memory. The robotics and VLA papers provide the closest layout references. The two language-model surveys provide additional examples of long-form taxonomy and evolution diagrams.
